## 第一部分：先花 1 分钟搞懂它在干什么

### C 盘是什么？

你可以把电脑想成一个大房子，**C 盘就是这栋房子的主仓库**。

Windows 系统、你装的微信、QQ、浏览器、游戏，全都放在这个仓库里。仓库越大，能放的东西越多；仓库塞满了，电脑就会变卡、甚至报警说"磁盘空间不足"。

### 那"垃圾文件"又是什么？

就像你做饭会产生菜叶、拆快递会产生纸箱一样，**电脑每干一件事，都会产生一些"用不上的东西"**：

| 生活里的比喻 | 电脑里的名字 | 举几个例子 |
|---|---|---|
| 拆完快递的纸箱 | 临时文件 | 软件安装到一半留下的残骸 |
| 写作业时的草稿纸 | 缓存文件 | 浏览器记下的网页图片，为了下次打开快点 |
| 看视频的缓冲 | 应用缓存 | 微信、抖音、B 站存下的临时画面 |
| 垃圾桶里的东西 | 回收站 | 你删掉的文件，其实还在占地方 |

这些东西**留着也不会让电脑更快，删掉也不会丢任何个人文件**（照片、文档、聊天记录都安全）。

### 这个工具干什么？

它就是个**保洁员**：

1. 进屋转一圈，把能扔的东西**全部列成一张清单**（写清楚是什么、多少项、多大）
2. 把清单拿给你看，**你勾选**要扔哪些
3. 你说"开始"，它才动手
4. 干完活给你一张**账单**：扔了多少、腾出多少空间

**关键点：它不会自作主张。你不点"一键清理"，它一个文件都不会删。**

## 第四部分：最简单的用法（推荐，4 步搞定）

### 第 1 步：把程序下载到电脑上

在网页上找到 **`CleanCDrive.exe`** 这个文件，点击下载。

> 💡 **下载到哪了？**
> 大多数浏览器会存到"下载"文件夹。如果找不到，按键盘上的 `Win 键 + E` 打开文件资源管理器，左边点一下"下载"就能看到。

### 第 2 步：如果下载的是压缩包，先解压

下载下来的文件名如果**以 `.zip` 结尾**，说明它是个"压缩包"，就像快递还没拆的箱子。**必须先解压再用**。

**怎么解压？**

1. 找到这个 `.zip` 文件
2. **右键**点它
3. 菜单里选 **"全部解压缩..."**（Windows 11 上叫"全部提取..."）
4. 弹窗里点 **"提取"**
5. 会多出一个文件夹，**打开这个文件夹**

> ⚠️ **这一步最容易被忽略！**
> 千万**不要**在压缩包里面直接双击 exe。那样程序可能跑不起来，或者设置存不下来。
> 判断方法：看窗口地址栏，如果里面有 `.zip` 字样，说明你还在压缩包里面。

### 第 3 步：双击运行

在解压出来的文件夹里，找到 **`CleanCDrive.exe`**（图标是一个蓝色方块），**双击它**。

稍等几秒钟（第一次打开会慢一点点），界面就出来了：

![主界面](https://c-drive-cleaner-12094.app.workbuddy.host/images/01-main.png)

> 💡 **如果双击后没有任何反应**，或者闪过一个黑窗口就没了，请直接跳到
> [第八部分：如果双击没反应](#第八部分如果双击没反应--三种备用方法)。

### 第 4 步：开始清理

程序会自动扫描。看到清单后，就是**刷卡消费**的流程：

1. 看一眼清单，看看有没有你不想删的 → **把它的勾去掉**
2. 点右下角的橙色 **"一键清理"** 按钮
3. 弹出确认框，**再核对一遍**，点"确认清理"
4. 等它干完活，会弹出报告，告诉你腾出了多少空间

**恭喜，C 盘已经变干净了。**

## 第六部分：手把手教你清理 C 盘

跟着做，一步一步来，不要跳。

### 步骤 1：确认在"磁盘清理"页面

看第 ③ 区，第一个按钮 **"磁盘清理"** 应该是**深蓝色**（选中状态）。如果是灰色的，点它一下。

### 步骤 2：等它扫描完

刚打开程序时，它会自动扫描，底部灰字会显示：

```
扫描完成：366 个文件可清理，回收站 101 项
```

看到这句话就说明扫完了。如果一直是"正在扫描"，等 10~30 秒即可（磁盘越满越慢）。

### 步骤 3：看懂清单里的每一行

每一行长这样：

```
☑  系统临时: %TEMP%        [系统临时]              23 项
                                                   41.33 MB
```

从左到右四块信息：

| 位置 | 含义 | 说明 |
|---|---|---|
| ☑ 方框 | **勾选框** | 打钩 = 要清理，点一下可以切换 |
| 中间文字 | **这是什么** | 比如 `%TEMP%` 是"临时文件夹"，`Edge 缓存` 是"Edge 浏览器的缓存" |
| 灰色小标签 | **类型** | `系统临时` = Windows 自己产生的；`应用缓存` = 软件产生的 |
| 最右边 | **项数 + 大小** | `23 项 41.33 MB` = 这里面有 23 个文件，一共 41.33 MB |

### 步骤 4：决定勾选哪些

**最省事的做法**：不用改，程序默认已经帮你全勾上了（因为清单里的都是安全的）。

**想保留某个的话**：点一下那一行左边的小方框，钩消失就行。这一行就不会被清理。

> 💡 **不确定某个能不能删？**
> 每一行右边都写着大小。你可以只保留大的、删小的，或者反过来。**没有标准答案**，看清名字再决定。

### 步骤 5：看底部数字变化

每勾掉一行，底部第 ⑦ 区的数字会立刻变：

```
已选：462 项 · 预计释放 254.33 MB
```

这个数字就是"待会儿能腾出多少空间"。觉得够了就行。

### 步骤 6：点"一键清理"

看第 ⑦ 区，最右边那个**橙色按钮**，写着"一键清理"。点它。

### 步骤 7：在确认框里最后核对一次

会弹出一个窗口，把**所有将要删除的项目**再列一遍，并且明确告诉你：

- 要删几个文件
- 预计释放多少
- 哪些目录是受保护的（灰显，不会被删）

**这是你最后反悔的机会**。确认没问题，点"确认清理"。

> 🔒 受保护的系统关键目录（比如 `C:\Windows`、`C:\Program Files`）只会**显示出来给你看**，
> 无论你点什么都**不会被删除**。

### 步骤 8：看报告

清理完成后弹出结果窗口，会告诉你：

- 清理前 C 盘可用空间：**41.56 GB**
- 清理后 C 盘可用空间：**41.81 GB**
- **实际释放：254.33 MB**
- 分类明细：每一项扔了多少

点"打开报告目录"可以看到完整的记录文件（`cleanup_report_日期时间.log`），下次想查也能找到。

**完成！** 整个过程不超过一分钟。

## 第七部分：五个页面分别是什么

点第 ③ 区那排蓝色按钮切换页面。下面逐个讲。

### 🧹 页面 1：磁盘清理

**这是最常用的一页**，上面已经详细讲过了。再总结一下：

- **干什么**：扫描 + 勾选 + 清理临时文件和缓存
- **什么时候用**：C 盘变红、空间不足、电脑变卡时
- **安全性**：⭐⭐⭐⭐⭐ 只删临时/缓存文件，不动任何个人数据

这一页还会显示**受保护的系统关键目录清单**（灰色、点不了），让你放心。

### 📦 页面 2：大文件扫描

![大文件扫描](https://c-drive-cleaner-12094.app.workbuddy.host/images/02-bigfile.png)

**干什么**：找出电脑里体积特别大的文件。

**怎么用**：

1. 在"阈值 (MB)"框里填数字，比如 `200` 表示"只找 200MB 以上的文件"
   - 填小一点（如 100）找出的文件多，填大一点（如 1000）只找巨无霸
2. 点 **"开始扫描"**
3. 结果按大小从大到小排列，显示：大小、最近修改时间、文件路径
4. 找到不想要的，选中后可以：
   - **定位文件**：在文件夹里把它高亮出来，你自己确认一下
   - **打开文件**：直接打开看看是什么
   - **送回收站**：删掉（**还能从回收站还原**，不放心就先放回收站）

**什么时候用**：清理完缓存空间还是不够、想知道空间到底去哪了。

> 🔒 系统目录里的文件、以及 `.exe` / `.dll` / `.sys` 这类程序文件，**一律不允许删除**，
> 程序会直接拦住并提示你。

### 📊 页面 3：内存与进程

![内存与进程](https://c-drive-cleaner-12094.app.workbuddy.host/images/03-memory.png)

**干什么**：看看内存用得怎么样，找出偷偷吃内存的软件。

页面分三块：

**① 三个数字贴片**（最上面一行）

| 贴片 | 含义 |
|---|---|
| 物理内存使用率 | 内存用了百分之多少，**超过 85% 就该注意了** |
| 已用内存 | 用了多少 / 一共多少 |
| C: 可用空间 | 硬盘还能装多少东西 |

**② 实时曲线**（中间）

一条每秒更新的折线图，展示最近 60 秒内存和硬盘的变化。线条一直往上爬，说明有软件在偷偷吃资源。

**③ 后台进程内存占用排行**（下面表格）

列出正在运行的程序，按占用内存从大到小排列：

| 列 | 含义 |
|---|---|
| PID | 程序的编号（系统内部用，你不用记） |
| 进程名 | 程序名字，比如 `chrome` 就是 Chrome 浏览器 |
| 内存占用 | 它吃了多少内存 |
| 窗口标题 | 窗口上显示的名字 |

**想关掉某个占内存的程序**：

1. 在表格里**点一下那一行**选中它（按住 Ctrl 可以选多个）
2. 点右上角红橙色 **"结束选中进程"**
3. 弹出确认框，核对 PID 和名字
4. 确认

> ⚠️ **重要**：这里的"结束"就等于**强制关掉那个软件**。如果那个软件里有没保存的东西，会丢失。
> 所以：**关之前先自己看一眼那个软件，确认里面没有未保存的内容。**
>
> 🔒 系统核心进程（显卡、声卡、Windows 自己的进程等约 40 个）**根本不会显示在这个列表里**，
> 所以不可能误关导致电脑出问题。
>
> 💡 表格里标着"可安全关闭"的，是常见的、关掉没影响的程序（比如已经打开很久的浏览器、聊天软件）。

### ⏰ 页面 4：自动清理

![自动清理](https://c-drive-cleaner-12094.app.workbuddy.host/images/04-auto.png)

**干什么**：让电脑自己按时清理，不用你操心。

**怎么设置**：

| 设置项 | 怎么填 |
|---|---|
| **执行频率** | 下拉选择：每天 / 每周 / 每小时 / 每次开机登录 |
| **执行时间** | 填时间，比如 `03:00` 表示凌晨 3 点（**建议挑你不用电脑的时候**） |
| **启用自动清理** | 打钩才生效 |
| **清理目标** | 勾选要清哪些：系统临时文件 / 应用缓存 / 回收站 |

填好后点蓝色 **"保存并注册计划任务"**。会弹窗告诉你在向 Windows 登记一个定时任务：

- 名字叫 `CleanCDrive_AutoClean`
- 到点后**静默运行**（不弹窗，不打扰你）
- 每次运行都会生成一份报告文件

**其他三个按钮**：

| 按钮 | 作用 |
|---|---|
| **取消计划任务** | 不想自动清理了，点这个删掉定时任务 |
| **立即执行一次** | 现在就跑一次清理（测试设置对不对） |
| **查看任务状态** | 看看定时任务有没有登记成功 |

> ⚠️ 如果提示"权限不足"，把程序**用管理员身份运行**（见 [常见问题 Q4](#q4-提示权限不足怎么办)）。
>
> 💡 **建议**：先手动清理几次，熟悉了再开自动清理。

### 🚫 页面 5：排除设置

![排除设置](https://c-drive-cleaner-12094.app.workbuddy.host/images/05-exclude.png)

**干什么**：告诉工具"这些东西千万别动"。

三种排除方式：

| 方式 | 填什么 | 例子 |
|---|---|---|
| **保留路径** | 一个文件夹的完整路径 | `C:\我的重要缓存` |
| **保留文件名模式** | 文件名规则，`*` 表示任意内容 | `*.log`（所有 log 文件）、`important*`（important 开头的所有文件） |
| **文件年龄** | 只清理超过 N 天没动过的文件 | 填 `7` = 7 天内的新文件不删 |

填好后点保存，会写进程序旁边的 `cleanup_config.ini` 文件。

> 🔒 **安全说明**：这个设置只能让清理范围**变小**（多保留一些），
> **不可能**让程序去删除系统目录。所以怎么填都不会出危险。

**什么时候用**：你有某个软件的缓存很重要不想清，或者想更保守一点。

## 第八部分：如果双击没反应 —— 三种备用方法

用 exe 是最省事的。但如果你的电脑因为各种原因打不开它，还有下面三条路。

### 方法 A：一键运行.bat（还是要装 Python，但不用敲命令）

如果你电脑上**已经装了 Python**，这是最简单的办法。

1. 在文件夹里找到 **`一键运行.bat`**
2. **双击它**
3. 会弹出一个黑色窗口，自动检测 Python 并启动程序
4. **如果提示没装 Python**，窗口里会直接告诉你去哪下载，按它说的做就行

> 💡 `一键运行.bat` 是干什么的？
> 它是一个"自动化脚本"——把你要敲的好几行命令**预先写好了**，你双击就等于替你敲了一遍。
> 这对不懂命令行的用户最友好。

**如果上面的黑色窗口一闪就没了**：说明可能报错了。解决方法是**右键**点 `一键运行.bat`，选"在终端中打开"，然后手动敲：

```bat
一键运行.bat
```

这样窗口就不会自动关闭，报错信息能看清楚，方便截图发给我。

### 方法 B：命令行安装 Python 并运行（最完整的办法）

如果你连 Python 都没有，也不想装 exe，那就按下面的步骤来。**每一行都解释了在干什么。**

#### B-1. 检查电脑上有没有 Python

1. 按键盘 `Win 键 + R`
2. 输入 `cmd`，回车 → 弹出一个黑色窗口（这就是"命令提示符"）
3. 在黑色窗口里输入下面这行，然后回车：

```bat
python --version
```

**会出现两种结果**：

| 看到什么 | 说明 | 下一步 |
|---|---|---|
| `Python 3.12.2` 这样的文字 | ✅ 已经装好了 | 跳到 **B-3** |
| `'python' 不是内部或外部命令...` | ❌ 还没装 | 继续 **B-2** |

#### B-2. 安装 Python

**方法一：图形界面安装（推荐）**

1. 打开浏览器，访问 <https://www.python.org/downloads/>
2. 点页面上那个**大大的黄色按钮** "Download Python 3.x.x"
3. 下载完，**双击**安装包
4. ⚠️ **最关键的一步**：在安装界面**最底部**，有一个复选框
   **`Add python.exe to PATH`**，**一定要打上钩**！
   很多人失败就是因为漏了这一步。
5. 点 **"Install Now"**，等进度条走完
6. 看到 "Setup was successful" 就成功了，点 Close

**方法二：用命令行安装（适合会用一点电脑的人）**

打开"命令提示符"（`Win + R` → 输入 `cmd` → 回车），逐行输入：

```bat
:: 用 Windows 自带的 winget 安装 Python，并自动加入 PATH
winget install -e --id Python.Python.3.12
```

如果提示找不到 `winget`（老版本 Windows 没有这个工具），就老实用上面的"方法一"。

#### B-3. 用命令行把程序跑起来

在命令提示符里，**一行一行**输入（每行回车一次）：

```bat
:: 第 1 行：切换到程序所在的文件夹
::          把下面的路径改成你自己的（就是你存放 CleanCDrive.py 的那个文件夹）
cd /d "D:\我的工具\C-Drive-Cleaner"

:: 第 2 行：看看文件夹里有没有主程序，有的话会列出这个文件名
dir CleanCDrive.py

:: 第 3 行：启动图形界面
python CleanCDrive.py
```

程序界面就会出来。

> 💡 **怎么知道我该写什么路径？**
> 打开存放程序的文件夹，**点一下顶部地址栏**，路径就变成了可复制的文字，
> 按 `Ctrl + C` 复制，粘到 `cd /d "` 后面即可。注意路径要用**英文双引号**包起来。

#### B-4.（可选）用 pip 安装依赖 / 打包成 exe

如果你想让这个程序变成"双击就能用的 exe"，在同一个命令提示符窗口里依次运行：

```bat
:: 安装打包工具（只需运行一次，需要联网）
python -m pip install --upgrade pyinstaller

:: 把 Python 程序打包成单个 exe 文件
:: --onefile   = 打包成一个文件
:: --windowed  = 运行时不要黑窗口
python -m PyInstaller --noconfirm --clean --onefile --windowed --name CleanCDrive --add-data "cleanup_config.ini;." CleanCDrive.py

:: 打包完成后，exe 就在下面这个位置
dir dist\CleanCDrive.exe
```

打包需要 1~3 分钟，完成后去 `dist` 文件夹里拿 `CleanCDrive.exe`。

> 💡 **`pip` 是什么？**
> 它是 Python 的"应用商店"，`pip install 名字` 就是从商店里下载并安装一个工具。
>
> 💡 **为什么这个程序不需要装任何第三方库？**
> 因为它用的是 Python 自带的 `tkinter` 画界面，不依赖任何外部组件，所以特别轻。

### 方法 C：自己打包一个 exe（体验版）

已经放在文件夹里了：**双击 `一键打包exe.bat`**，它会自动：

1. 检查有没有 Python
2. 自动安装 PyInstaller
3. 自动打包出 `dist\CleanCDrive.exe`

全过程不需要你输入任何命令，只要等着就行。

### 方法 D：用「运行库启动器」（最省心，推荐优先试）

如果 `dist\CleanCDrive.exe` 在**你自己的电脑**上双击没反应（尤其是一台从没装过
编程环境的"干净"电脑），十有八九是**缺了运行库**——这个程序用 Python 打包，
运行时需要系统里有 **Microsoft Visual C++ Redistributable（2015–2022）**。

我们已经帮你做好自动处理了：

1. 在文件夹里找到 **`CleanCDrive-Launcher.bat`**（运行库启动器）
2. **双击它**
3. 它会先自动检查本机有没有运行库：
   - **有** → 直接帮你打开程序；
   - **没有** → 弹窗问你要不要**一键下载并安装**（需要联网；安装时会弹出
     Windows 管理员授权窗口，点「是」即可），装完自动打开程序。
4. 你只需要在弹窗里点「是 / 否」，不用懂任何命令。

> 💡 这个启动器本身**不依赖任何运行库**，所以哪怕 exe 因为缺运行库打不开，
> 启动器也能正常跑起来、帮你修好它。平时直接双击 exe 就行；只有在"打不开"
> 的时候，才改用启动器。

另外，程序**自己在启动时也会先做一次环境自检**：发现缺少运行库（或系统版本
过低、临时目录空间不足等）会弹窗**声明**具体问题，并在你同意后自动修复——
所以多数情况下你甚至不用手动去点启动器。

### 三种方法怎么选？

| 你的情况 | 推荐 |
|---|---|

## 第九部分：常见问题（遇到问题先看这里）

### Q1：清理会删掉我的照片、文档、微信聊天记录吗？

**不会。**

程序有一份"白名单"，**只**能扫描和删除下面这些地方：

- Windows 的临时文件夹（`%TEMP%`、`C:\Windows\Temp`）
- 浏览器的缓存目录
- 各种软件的缓存和日志目录（只删里面的缓存文件）
- 回收站

**照片、文档、桌面文件、微信聊天记录、游戏存档**这些都不在白名单里，程序**连看都不会看**。

而且删除前会对**每一个文件**再检查一遍路径，只要不在白名单内，直接拒绝删除。

### Q2：会不会误删导致系统坏掉？

不会。程序有三道锁：

1. **只扫白名单**：不在名单里的目录根本不扫描
2. **删前逐文件复核**：每个文件删除前都再验证一次完整路径
3. **受保护目录只展示**：`C:\Windows`、`C:\Program Files`、`C:\Users` 等关键目录，
   在界面上**只显示出来给你看**（灰色的），点不了的，永远不会被删

另外，核心系统进程（约 40 个）也被硬编码保护，不会出现在进程列表里，不存在误关的可能。

### Q3：双击后 Windows 弹出蓝色窗口说"已保护你的电脑"怎么办？

这是 Windows 对所有"没有花钱购买数字签名"的免费小软件的**统一提示**，不是病毒警告。

**怎么通过**：

1. 点窗口上的 **"更多信息"** 这几个小字
2. 会多出一个按钮 **"仍要运行"**
3. 点它，程序就启动了

> 💡 如果杀毒软件直接删掉了这个 exe，在杀毒软件的"隔离区"里可以把它**还原**，
> 并选择"信任此文件"。原因是这类工具会读取文件列表、删除文件，杀毒软件会误判。
> 你可以**先看源码再决定**——本仓库根目录的 `CleanCDrive.py` 就是全部代码，没有任何联网上传行为。

### Q4：提示"权限不足"怎么办？

有些目录（如 `C:\Windows\Temp`、回收站）需要**管理员权限**才能清理。

**做法**：

1. 右键点 `CleanCDrive.exe`
2. 选 **"以管理员身份运行"**
3. 如果弹出"是否允许此应用对你的设备进行更改"，点 **"是"**
4. 程序会以更高权限打开，就能清理这些目录了

### Q5：为什么有些文件删不掉？

**正常的，不用管。**

有些临时文件正被正在运行的程序占用（比如你开着微信，微信的缓存文件就是锁着的），
Windows 不允许删除正在使用的文件。

程序的做法是：**跳过去，计入"失败"，继续清理其他文件**，不会因此中断或崩溃。

想删得更干净？**把不用的软件先关掉，再清理一次**。

### Q6：清理完之后，空间怎么没涨多少？

几种可能：

1. **回收站没勾选**：回收站里的东西也是占空间的，检查一下有没有勾上
2. **程序显示的是"预估"**：实际删除时会跳过被占用的文件，所以实际值可能略小于预估
3. **大头不在缓存里**：你的空间可能被少数几个大文件吃掉了 → 去 **"大文件扫描"** 页找找看

### Q7：清理完文件还能找回吗？

分两种情况：

- **回收站里的东西**：清空就没了，这是不可恢复的（就和平时清空回收站一样）
- **"大文件扫描"里送回收站的文件**：**可以还原**，去 Windows 回收站里右键选"还原"

所以对不确定的文件，**优先用"大文件扫描"页的"送回收站"功能**，比直接删更保险。

### Q8：这个程序会联网吗？会上传我的文件吗？

**不会。**

程序是纯本地运行的，**没有任何联网功能**，代码里没有任何网络请求。
它不知道你是谁，也不会把你的任何信息发到任何地方。

你可以自己看代码验证：`CleanCDrive.py` 里没有 `requests`、`urllib`、`socket` 这类网络库的调用。

### Q9：我开了自动清理，但它好像没执行？

按顺序检查：

1. **"启用自动清理"打钩了吗？** 没打钩不会生效
2. **点过"保存并注册计划任务"了吗？** 光填不保存不算
3. **点"查看任务状态"**，看看任务是否登记成功
4. **是不是需要管理员权限？** 用管理员身份重新打开程序，再保存一次
5. **电脑当时开机了吗？** 比如设了凌晨 3 点，但电脑那时候是关机的，就不会执行
   → 这种情况建议改成"每次登录"或你不关机的时间点

### Q10：程序卡住 / 一直转圈怎么办？

- **扫描时**：磁盘文件多的时候，扫描需要几十秒，耐心等一下
- **清理时**：会显示进度条，别关窗口
- **真的卡死了**：按 `Ctrl + Shift + Esc` 打开任务管理器，找到 `CleanCDrive`，
  右键"结束任务"，然后重新打开即可。**中途关掉不会损坏系统**，只是这次没清完。

### Q11：能清理 D 盘吗？

目前只针对 **C 盘**（因为 C 盘最容易爆满、后果最严重）。

### Q12：我想自己改一下，可以吗？

可以，完全开源。技术细节见 [`docs/技术文档.md`](docs/技术文档.md)。

### Q13：换一台电脑打开，提示"由于找不到 VCRUNTIME140.dll / MSVCP140.dll，无法继续执行代码"？

这是典型的**缺少 Visual C++ 运行库**。请改用本文件夹里的
**`CleanCDrive-Launcher.bat`** 双击运行——它会检测并自动帮你安装好运行库，然后
正常打开。（程序自己启动时也会先做环境自检；只有"连启动都失败"这种极端情况，
才需要启动器来兜底。）

## 第十部分：为什么可以放心用（安全承诺）

这个工具在设计上就假设"用户可能会点错"，所以每一步都上了锁：

| 保护机制 | 大白话解释 |
|---|---|
| **白名单扫描** | 只去规定好的几个"垃圾堆"里找东西，别的地方不进 |
| **删除前二次复核** | 每删一个文件前，都再检查一遍"它确实在垃圾堆里吗？" |
| **受保护目录只读展示** | 系统关键目录只能看，不能碰 |
| **必须手动确认** | 你不点"一键清理"，它什么都不做 |
| **二次确认弹窗** | 点完还要在弹窗里再确认一次，并列出完整清单 |
| **关键进程保护** | 40 个左右的核心进程直接不显示，无法误关 |
| **大文件走回收站** | 大文件一律送回收站，**可以还原**，不做永久删除 |
| **失败即跳过** | 文件被占用删不掉，跳过就行，不报错、不中断 |
| **完全离线** | 没有任何联网功能，不上传任何东西 |

**最重要的一条**：这个工具**只做减法中最安全的那部分**——
它不碰注册表、不卸载软件、不动个人文件、不移动任何数据。

## 第十一部分：怎么把它从电脑里删掉

这个工具是**绿色免安装**的，删除非常简单：

### 如果你用的是 exe

1. 找到存放 `CleanCDrive.exe` 的文件夹
2. **整个文件夹直接删除**（右键 → 删除）就行

### 如果你开了自动清理

**先取消定时任务，再删文件**，否则电脑会一直尝试运行一个不存在的程序：

1. 打开程序 → 切到 **"自动清理"** 页
2. 点 **"取消计划任务"**
3. 确认后，再删除文件夹

### 手动清理残留（可选）

程序会在自己旁边生成两类文件，可以一并删掉：

| 文件 | 是什么 |
|---|---|
| `cleanup_report_*.log` / `.html` | 历次清理的报告 |
| `autorun_report_*.log` / `.html` | 自动清理生成报告 |
| `cleanup_config.ini` | 你保存的设置 |

删掉它们**不会影响系统**，只是下次要重新设置一遍。
